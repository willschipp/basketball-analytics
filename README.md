# basketball-analytics

## Structure

- project is a Proof of Technology for using computer vision to detect basketball statistics
- builds upon existing opensource models and data

### UX
`frontend/ux`
- react + vite.js with bootstrap
- `npm run dev` includes mocks for most APIs exposed
- `npm run build` puts outputs in `server/src/ux` to be used by the `aiohttp` based python app
